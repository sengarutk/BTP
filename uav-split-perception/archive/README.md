# Archive

Files here are **not used** to produce any result in `experiments/results` or the paper.
They were superseded during the 2026-09 overhaul and are kept only for reference:

- `legacy/evaluation/`, `legacy/simulation/` — earlier benchmark, energy, swarm, and plotting
  scripts. They used inconsistent hardware models, a link model that could exceed capacity,
  COCO128 training images for accuracy, and hard-coded constants.
- `legacy/omnetpp/` — OMNeT++/INET topology files that were never runnable.
- `legacy/results/`, `legacy/paper_figures/`, `legacy/table_*.tex` — outputs of the scripts above.
- `legacy/docs/`, `legacy/walkthrough.md` — specifications whose numbers no longer match any code.

Everything can also be recovered from git history. Delete this directory if you do not need it.
